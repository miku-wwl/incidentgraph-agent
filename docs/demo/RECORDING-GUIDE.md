# Local demo recording guide

## Before recording

- Use the setup steps in the README and a dedicated, new private Action home.
- Confirm the local FalkorDB container and Ollama model are ready.
- Use the local Web Console at `http://127.0.0.1:8765/`.
- Close unrelated windows and keep credentials, capability data, `.env`, and private database files off-screen.
- Record at 1080p or higher with readable browser text. Use a screen recorder installed and approved by the operator; no recording software or recording artifact was used for the current Phase 4 evidence.
- Start with a fresh proposal only if the operator has intentionally selected a new action home. Never delete or reset an existing home to prepare a recording.

## During recording

- Follow [VIDEO-SCRIPT.md](VIDEO-SCRIPT.md) and [SHOT-LIST.md](SHOT-LIST.md).
- State that graph records are synthetic and that causality is unproven.
- Pause at approval, authorization, and execution. The owner personally reviews and enters each exact phrase, or rejects/stops.
- If an operation is interrupted or returns `Unknown`, inspect persisted status and receipt. Do not retry.
- Do not edit, splice, or narrate a state that was not observed.

## After recording

- Replay the whole video and confirm that each gate and result is visible and legible.
- Verify every claimed ticket and receipt against persisted Action status and ticket data.
- Add the video file or an unlisted video link only after the owner reviews it. Do not include private local database files in the repository or submission.
